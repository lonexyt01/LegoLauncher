LegoLauncher (Pojav asosida) - o'zi ishlaydigan Minecraft Java launcher
Boshqa ilova KERAK EMAS: APK o'zi papka (games/LegoLauncher) va JRE'ni o'rnatadi, o'yinni o'zi ishga tushiradi.

APK olish - 3 usul:
A) GitHub (eng oson, telefondan ham): yangi repo -> shu zip ichidagini yuklang -> Actions ->
   "Build LegoLauncher" -> Run workflow -> "LegoLauncher-apk" artifact'ini yuklab oling.
   Run workflow oynasida Pojav yoki Zalith'ni tanlash mumkin.
B) Windows: Git, JDK 17, Android SDK o'rnating, ANDROID_HOME belgilang, build.bat ni oching.
C) Linux/macOS: build.sh

Eslatma: muhitda internet yo'q edi, shuning uchun sinab ko'rilmagan. Xato chiqsa matnini yuboring.
